## Experiment: E-041 — A valid constraints-only contract is rejected

- **Date:** 02.11.2026
- **Status:** completed
- **Theory:** `INV-051` allows a gated verdict's `decisive_evidence_ids` to carry either a critical claim or — at MINIMAL, where `claims[]` may be empty — a critical acceptance condition via `evidence[].supports_ac_ids[]`. The gate only accepts the claim path, so a correct AC-only MINIMAL contract is rejected as ungrounded. A gate that rejects valid records is as damaging as one that admits invalid ones: the optimizer learns to add a decorative claim instead of grounding the AC.
