## Experiment: E-047 — The Hermit adapter is never loaded

- **Date:** 02.11.2026
- **Status:** completed
- **Theory:** Hermit 0.1.0 resolves `start_from` to a directory only when that directory carries `adapter.yaml`; otherwise it treats the value as a git ref. `optimization/hermit/adapter/` has no manifest, so `hermit train` exits before any model call, while `make hermit-check` silently skips `check_spec` and still reports `[ok] template` — the check is fail-open. The 3026-byte `adapter/ADAPTER.md` therefore never enters training; the run root is seeded from the built-in `prompt_only` template instead.
