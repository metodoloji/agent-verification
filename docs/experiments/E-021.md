## Experiment: E-021 — Contract links do not reciprocate

- **Date:** 02.11.2026
- **Status:** completed
- **Theory:** The spec makes every link two-sided (`INV-017`, `INV-038`, `INV-053`): a claim's `test_ids` and a test's `target_claim_ids` must agree, the same holds for ACs, and evidence support links mirror the claim/AC `evidence_ids`. The gate only reads one direction for coverage, so a contract can list a test that does not target the claim, target a dangling id, or carry one-sided evidence links and still PASS.
- **Hypothesis:** H-021: "defect_rate >= 0.5"
- **Measurement Metrics:** defect_rate >= 0.5 — proportion of eight link probes still admitted (unitless)
- **Experiment Design:** `scripts/bench/bench_optimization.py --suite links` adds eight probes: a claim listing a non-targeting test, a test targeting a dangling claim, one-sided and dangling evidence links on both the claim and AC side, a one-sided AC test link, a critical AC with no critical test, and a prompt probe for the missing rule. The ten earlier suites stay unchanged. `--control clean` must fail the claim.
