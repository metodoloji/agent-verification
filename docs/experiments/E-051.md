## Experiment: E-051 — The dataset check rewrites instead of verifying

- **Date:** 03.11.2026
- **Status:** completed
- **Theory:** `make dataset` runs `build_dataset.py --check`, but the `--check` branch still calls `build(args.out)`, which writes every split, and then compares only the case counts (70/11/9). `evals/cases.md` can change and the committed `dataset/data/*.jsonl` can drift — the command rewrites the drift away and prints `DATASET OK`. Hermit's builder has no check mode at all, and `make smoke` validates neither derived file.
- **Hypothesis:** H-051: "defect_rate >= 0.5"

- **Experiment Design:** `scripts/bench/bench_optimization.py --suite freshness` adds five probes: `--check` writes instead of compares, it compares only counts, the Hermit builder has no check, `hermit-data` has no guard, and `smoke` omits the Hermit data check. The twenty-four earlier suites stay unchanged. `--control clean` must fail the claim.
